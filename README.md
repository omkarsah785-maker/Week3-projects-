Practical Objective and Activities

The aim of this practical was to unlock two password-protected PDF files using password-cracking techniques.

Using John the Ripper (JTR) and the password-cracking and hashing tools provided by NETWORKWALKS, I performed password

recovery exercises and successfully unlocked both PDF files.

Key Learnings

Understanding password-cracking techniques.

Exploring password hashes and password security.

Identifying risks associated with weak passwords.

Understanding the importance of strong password protection.

Conclusion

These practical exercises strengthened my understanding of password security and the role of ethical hacking in identifying

vulnerabilities within authorized environments.
